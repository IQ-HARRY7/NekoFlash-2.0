## Approved Design Decisions

**Status:** Design approved. Only minimal **Sideload REV3** (REV5) has been ported into the source code. Design and code remain separate project phases.

- **REV2:** `NekoFlash-2.0-MASTER-DECISIONS-2026-10-09-RU-REV2.md`, decision register CSV, and static audits. Five tabs, unified shell, USB status strip, and terminal.
- **REV3 (Approved):** `NekoFlash-2.0-SIDELOAD-REV3-APPROVED-2026-10-10.md` — third tab is dedicated Sideload only, without extra miscellaneous ADB functions.
- **REV4 (Approved):** `NekoFlash-2.0-UNLOCK-REV4-APPROVED-2026-10-10.md` — Mi Unlock workflow, two visual states, outcome verification after USB reconnect.

**Precedence:** Later decisions take precedence: REV4 / REV3 override any conflicting earlier REV2 mentions. The legacy/separate NekoFlash Pro branch/project is not used.

HTML and PNG design mockups are retained solely for visual reference and UI alignment. They do not represent executable Android application screens.

# NekoFlash 2.0 — согласованные решения

Статус: **дизайн согласован**, перенесён в исходники только минимальный **Sideload REV3** (REV5). Дизайн и код — разные этапы.
